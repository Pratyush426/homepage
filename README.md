### Key Projects
1. **Decoupled Sentence Segmentation on Noisy Text** (*CAIR, DRDO*)
   - Two-phase architecture combining a fast 21-rule heuristic classifier (0.22 ms latency) with a contextual DeBERTa-v3 router across 5 noise distributions (LibriSpeech, ICDAR, WNUT-17).
2. **ClawSwarm AI: Adaptive Multi-Agent Orchestration** (*Independent Research*)
   - Decentralized multi-agent framework utilizing 6D Exponential Moving Average (EMA) skill vectors and contextual bandits with peer heartbeat leader election (63% cumulative regret reduction).
3. **Multimodal Deepfake Detection via Synchronization Fusion** (*MSRIT*)
   - Audio-visual synthetic media detector leveraging Synchronization-Aware Feature Fusion (SAFF) and CM-GAN, evaluated across LAV-DF (94.57% accuracy) and cross-lingual Hindi benchmarks (HAV-DF).
